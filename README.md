# Entre Lienzos y Acordes

Demo de videojuego desarrollada como Trabajo de Fin de Grado del Grado en Diseño y Desarrollo de Videojuegos.

## Descripción

*Entre Lienzos y Acordes* es un juego narrativo musical en el que el jugador gestiona la estabilidad emocional de los miembros de una banda durante su actuación. La experiencia combina exploración en primera persona, cinemáticas y minijuegos rítmicos sincronizados con la música en tiempo real.

## Escenas

| Escena | Descripción |
|---|---|
| **MainMenu** | Menú principal con acceso directo a cada modo |
| **Cinematica** | Secuencia narrativa introductoria con diálogos y Timeline |
| **LoopSongs** | Exploración libre del escenario con música adaptativa por zonas |
| **Minijuego** | Gestión de los cuatro personajes mediante minijuegos musicales |

## Minijuegos

- **Ritmo** — Taps sincronizados con el beat de FMOD
- **Afinación** — Mantener el tono en la zona correcta
- **Respiración** — Control de inhalación y exhalación

## Tecnología

- **Motor:** Unity 6 (6000.3.8f1)
- **Audio:** FMOD Studio 2.02.34
- **Render:** Universal Render Pipeline (URP)
- **Input:** Unity Input System
- **Lenguaje:** C#

## Cómo abrir el proyecto

1. Instalar **Unity 6000.3.8f1** desde Unity Hub
2. Instalar **FMOD Studio 2.02.34**
3. Clonar el repositorio y abrir la carpeta del proyecto desde Unity Hub
4. Construir los banks de FMOD desde FMOD Studio antes de ejecutar en Play Mode
